# QuantLab

An end-to-end quantitative trading research project.

## Objectives

- Learn quantitative trading fundamentals
- Analyze historical ETF prices
- Develop and backtest trading strategies
- Evaluate risk and performance
- Explore machine learning models

## Week 1

- SPY and QQQ historical data analysis
- Simple and log returns
- Annualized volatility
- Normalized price visualization
